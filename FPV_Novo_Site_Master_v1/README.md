# FPV — Novo Website · Master v1

Referência visual e funcional para a modernização do website da Federação Portuguesa de Vela.

## Objetivo
Este pacote consolida a arquitetura aprovada e os tipos de página necessários antes da implementação técnica em WordPress + Divi.

- Descobrir
- Competição (gateway para a plataforma operacional)
- Alto Rendimento
- Formação
- Clubes
- Notícias
- Federação
- myFPV

- Documentos
